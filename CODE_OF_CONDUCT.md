# Code of Conduct

## Our commitment

We are committed to a welcoming, harassment-free community. Be respectful, accept constructive feedback, and prioritise candidate privacy, fairness, and human dignity.

Harassment, discriminatory conduct, publication of private information, abusive behaviour, and attempts to use this project for unlawful or autonomous employment decisions are not tolerated.

## Scope and reporting

This code applies to project repositories, discussions, reviews, and other project spaces. Do not include real candidate records, confidential job information, or provider credentials in a report.

Report conduct concerns privately to the maintainers through the repository's private contact channel. Security vulnerabilities should follow [SECURITY.md](SECURITY.md). Maintainers may remove content or participation that violates these expectations.
